## MVP

Цель MVP — продемонстрировать новое визуальное направление сайта ЛХВЭ, базовую архитектуру Django-приложения, минимальное управление содержимым через Django Admin и возможность развернуть сервис в production-подобном окружении.

После согласования MVP структура сайта, модели данных и дополнительная функциональность будут проектироваться отдельно.

## Не входит в MVP

Следующие задачи выполняются только после согласования MVP:

* полноценное проектирование sitemap;
* модели сотрудников;
* персональные страницы сотрудников;
* научные направления;
* проекты;
* публикации;
* учебные материалы;
* галерея;
* полнофункциональные страницы всех разделов;
* поиск;
* английская версия;
* HTMX и дополнительная интерактивность;
* расширенная система прав;
* отдельная административная панель;
* полноценный набор автоматических тестов;
* production-инфраструктура повышенной отказоустойчивости;
* резервное копирование и мониторинг.

## Критерии готовности MVP

MVP считается готовым к демонстрации, если:

* [ ] главная страница имеет законченный современный UI/UX;
* [ ] сайт корректно отображается на desktop и mobile;
* [ ] основные пункты навигации открывают страницы-заглушки;
* [ ] через Django Admin можно создать или изменить объявление;
* [ ] опубликованное объявление отображается на главной;
* [ ] приложение собирается и запускается из Docker-образа;
* [ ] приложение доступно по публичному URL.
