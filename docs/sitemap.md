# Sitemap ЛХВЭ

## Публичная часть

- `/` — Главная
- `/about/` — О лаборатории
  - `/about/history/` — История лаборатории

- `/people/` — Сотрудники
  - `/people/<slug>/` — Персональная страница сотрудника

- `/science/` — Наука
  - `/science/directions/<slug>/` — Научное направление
  - `/science/projects/` — Научные проекты
  - `/science/publications/` — Публикации

- `/students/` — Студентам
  - `/students/materials/` — Учебные материалы
  - `/students/theses/` — Курсовые и дипломные работы

- `/news/` — Новости и объявления
  - `/news/<slug>/` — Отдельная публикация

- `/gallery/` — Галерея

- `/contacts/` — Контакты


## Служебные страницы

- `/admin/` — Django Admin
- `/sitemap.xml` — XML sitemap для поисковых систем
- `/robots.txt` — правила индексации
