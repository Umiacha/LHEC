# Карта маршрутов ЛХВЭ

Документ отражает маршруты из `config/urls.py` и `urls.py` приложений.
Это справочник для разработчиков, а не XML sitemap для поисковых систем.

## Языковые версии и параметры

Основной язык — русский: URL без префикса. Английская версия использует
`/en/`, например `/en/people/`. Префикс применяется ко всем маршрутам ниже,
кроме `/admin/` и `/media/`.

Параметры соответствуют Django URLconf: `<int:pk>` — числовой идентификатор,
`<slug:slug>` — slug, `<path:file_name>` — путь файла, который может содержать `/`.
Завершающие слеши указаны как в коде. Наличие маршрута не гарантирует
доступность конкретной записи или файла.

## Публичные страницы

| URL | Назначение |
| --- | --- |
| `/` | Главная, информация о лаборатории |
| `/about/` | Перенаправление 301 на главную соответствующего языка |
| `/about/history/` | История лаборатории |
| `/people/` | Сотрудники и студенты лаборатории |
| `/people/<int:pk>/` | Карточка сотрудника |
| `/science/` | Наука |
| `/science/directions/<slug:slug>/` | Научное направление |
| `/science/projects/` | Научные проекты |
| `/science/projects/<slug:slug>/` | Страница проекта |
| `/science/publications/` | Список публикаций |
| `/science/publications/<int:pk>` | Страница публикации (без завершающего слеша) |
| `/students/` | Студентам |
| `/students/study_materials/` | Учебные материалы |
| `/students/theses/` | Курсовые и дипломные работы |
| `/news/` | Новости и объявления |
| `/gallery/` | Галерея |
| `/contacts/` | Контакты |

Новости и галерея поддерживают пагинацию через `?page=<номер>`.

## Учебные курсы с ограниченным доступом

Следующие маршруты требуют права `education.view_internal_materials`:

| URL | Назначение |
| --- | --- |
| `/students/study_materials/courses/<slug:slug>/` | Курс и его лекции |
| `/lectures/preview/<path:file_name>/` | Просмотр PDF в браузере; другие форматы скачиваются |
| `/lectures/files/<path:file_name>/` | Скачивание файла лекции |

## Скачивание файлов

| URL | Назначение |
| --- | --- |
| `/materials/<int:pk>/download/` | Скачивание учебного материала |
| `/science/publications/files/<path:file_name>` | Скачивание файла публикации |
| `/science/diplomas/files/<path:file_name>` | Скачивание дипломной работы |
| `/science/dissertations/files/<path:file_name>` | Скачивание диссертации |

## Учётная запись и служебные маршруты

| URL | Назначение |
| --- | --- |
| `/account/login/` | Вход |
| `/account/logout/` | Выход (POST) |
| `/people/<int:pk>/edit/` | Редактирование собственной карточки после входа (GET, POST) |
| `/i18n/setlang/` | Смена языка средствами Django (POST) |
| `/admin/` | Django Admin; вложенные маршруты формирует Django |
| `/media/<path>` | Выдача медиафайлов средствами Django только при `DEBUG=True` |
