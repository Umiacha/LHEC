# Общие стили сайта

Общие компоненты применяются ко всем публичным страницам, включая вход и
редактирование профиля. Админка Django сохраняет собственное оформление.

## Исходники и сборка

- `assets/input.css` — точка входа Tailwind и палитра.
- `assets/styles/base.css` — шрифт, базовый цвет, фокус, якоря и уменьшение движения.
- `assets/styles/components.css` — визуальные роли общих элементов.
- `core/static/core/css/main.css` — результат `npm run css:build`; не редактировать вручную.

Компоненты находятся в слое `components`: утилиты Tailwind могут переопределять
их для конкретного расположения. Сетки, отступы между объектами и адаптивная
композиция остаются в HTML. Не копируйте оформление компонента набором утилит.

После изменения стилей запускайте `make styles`: команда собирает CSS и выполняет
`collectstatic`. Один `npm run css:build` обновляет исходную статику приложения,
но не копию в `staticfiles`, которую может раздавать WhiteNoise / веб-сервер.
Для разработки с Django `runserver` и отслеживанием CSS есть `make dev`.
После обновления статики в работающем production-процессе перезапустите его,
чтобы обновить загруженный манифест; при старом CSS в браузере обновите страницу
без кеша (Ctrl+Shift+R).

## Значения

Тёмно-синий — структура и основные действия. Серый — текст и метаданные.
Бирюза — надзаголовки и небольшие акценты, а не универсальный признак ссылки.
Красный — ошибки. На тёмном фоне используются белый текст и светлая бирюза.

- `hero-title`: заголовок главной 40/52/64 px.
- `feature-title`: заголовок презентационного блока 30/40 px; наследует цвет фона.
- `feature-section`: просторные отступы главной 64/80/112 px.
- `card-frame`: оболочка карточки без внутренних отступов для фотографий и лекций.
- `button-accent` и `button-inverse`: основная и дополнительная кнопки на тёмном фоне.
- `file-control`: поле загрузки файла.
- `page-container`: общая ширина 1280 px с боковыми полями 24/32 px.
- `reading-width`: ограничение длинного текста до 768 px.
- `page-section`: вертикальные отступы 64/80 px.
- `page-label`: бирюзовый надзаголовок 14 px.
- `page-title`: заголовок страницы 36/48 px, вес 600.
- `section-title`: раздел страницы 24/30 px, вес 600.
- `card-title`: название объекта 20 px, вес 600.
- `page-intro`: вводный текст 18 px с интервалом 32 px.
- `metadata`: служебные сведения 14 px.
- `content-card`: самостоятельный объект, граница, скругление 20 px, без тени.
- `info-panel`: вспомогательная информация внутри объекта.
- `empty-state`: пояснение для пустого списка.
- `button button-primary`: основное действие; `button-secondary`: дополнительное.
- `text-link`: переход или скачивание; внутри обычного абзаца добавляйте `underline`.
- `form-control`: общее оформление поля.

Возврат оформляется через `core/components/back_link.html`, пагинация — через
`core/components/pagination.html`. Строка учебного файла —
`education/_material_row.html`. Ссылки возврата называют место назначения.
Каталог публикаций передаёт локальный `return_to`, сохраняя поиск и страницу;
детальная страница принимает только URL своего каталога.

Стрелки: ← возврат, → внутренняя страница, ↓ скачивание, ↗ внешний источник.
Карточки с текстом открываются по ссылке в названии. Действия строки файла справа
на широком экране и под описанием на телефоне. Заголовки могут переноситься.

При переносе следующих страниц используйте эти роли, сохраняя права доступа,
условия публикации и поведение форм. Презентационные блоки главной могут быть
просторнее каталогов: не нужно делать все страницы одинаковыми по плотности.
